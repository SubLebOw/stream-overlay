Trynd overlay – OBS scene file maker

Makes the Trynd Web Overlay scene collection (scenes Game + Queue) pointing at your site. Then in OBS: Scene Collection → Import → pick the downloaded file → tick it → Import, then choose it under Scene Collection.




After importing: double-click Game Capture and check it shows League (window: League of Legends.exe).
If it stays black (common on cafe PCs), hide Game Capture and show Display Capture, then pick the monitor in its properties.
Set Settings → Video → Base (Canvas) Resolution to 1920×1080.
